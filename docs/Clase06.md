# Clase 6 - Proyecto Node.js y package.json

## Objetivo
Convertir el repositorio en un proyecto Node.js y comprender `package.json`.

## Repositorio local
```text
C:\Proyectos\playwright-erp-automation
```

## Clonado
```bash
git clone https://github.com/jedumen1992-gif/playwright-erp-automation.git
```

## Inicialización
Se estudió `npm init` y finalmente se utilizó:
```bash
npm init -y
```

## package.json
Es la ficha técnica del proyecto Node.js. Contiene nombre, versión, descripción, scripts, repositorio, licencia y dependencias.

## Campos estudiados
- `name`
- `version`
- `description`
- `main`
- `scripts`
- `repository`
- `keywords`
- `author`
- `license`

## Idea principal
No queremos memorizar comandos: queremos entender qué problema resuelve cada uno y qué cambia en el proyecto.
