# Clase 5 - Preparación del entorno

## Objetivo
Preparar el entorno para trabajar profesionalmente con Playwright.

## Herramientas
- Visual Studio Code
- Git
- GitHub
- Node.js
- npm

## Conceptos
- **Git:** controla versiones e historial de cambios.
- **GitHub:** repositorio remoto.
- **Node.js:** permite ejecutar JavaScript fuera del navegador.
- **npm:** administra paquetes y dependencias de Node.js.

## Comandos
```bash
git --version
node --version
npm --version
```

## Git configurado
```bash
git config --global user.name "José Méndez"
git config --global user.email "jedu.men1992@gmail.com"

```
